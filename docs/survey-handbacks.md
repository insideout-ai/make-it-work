# Bounded exploration handbacks

Use this contract for substantial refinement and planning code surveys. It does
not replace mandatory project guidance, independent review or required report
readback. Single targeted lookups remain inline.

Dispatch a fresh write-capable general-purpose worker without inherited chat.
Keep application source read-only; authorize writes only to the survey artifact.
Resolve its output through the existing artifact resolver under this task's
`make-it-work/` directory. Give the worker the precise question, selected roots,
applicable project-loading requirements and exact report path. Preserve model
selection by the user or harness; do not add a model override for this change.

Save detailed findings and evidence in that report. Return a summary targeting
3,000 characters, containing:

- Conclusions relevant to the caller's question, including negative findings.
- Concrete source locations and the detailed report path.
- Dependencies and material risks that affect the next decision.
- Unverified claims, uncertainties, blockers and decisions needed from the user.

Do not paste source files, raw logs or the full research report into the handback.
Do not turn assumptions into facts. If material information cannot safely fit,
exceed the target and explain why; never mechanically truncate the result.
The coordinator reads relevant evidence sections as needed for its decision,
rather than automatically loading the full report or repeating the survey.
Existing contracts requiring complete evidence/report reads still take precedence.
