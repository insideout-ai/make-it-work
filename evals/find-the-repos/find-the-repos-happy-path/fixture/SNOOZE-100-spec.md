# SNOOZE-100 — Snooze an overdue reminder

**Status:** Answered

## Summary

When a user receives a reminder for an overdue task, let them snooze it for one hour instead of
resolving it immediately. Snoozing delays the next reminder delivery by one hour without changing
the task's due date or completion status.

## Acceptance Criteria

- AC1: A "Snooze 1 hour" action is available on a delivered overdue-task reminder.
- AC2: Choosing it delays the next reminder delivery for that task by exactly one hour.
- AC3: Snoozing does not change the task's due date, status, or completion state.
