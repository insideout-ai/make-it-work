# Product

Notifications Service schedules and delivers reminders when a task becomes overdue, and lets
users control how and when those reminders arrive.

## Use cases

| ID | Use Case | Actor | Trigger | Domains |
|---|---|---|---|---|
| UC-01 | Receive Overdue Reminder | User | Task's due date passes | notifications |
| UC-02 | Snooze Reminder | User | User taps "Snooze 1 hour" on a delivered reminder | notifications |
| UC-03 | Escalate Unacknowledged Reminder | System | Reminder unacknowledged for 1 hour | notifications |
