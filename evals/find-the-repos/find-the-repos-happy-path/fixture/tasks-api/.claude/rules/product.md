# Product

Tasks API owns task creation, assignment, and lifecycle status, including tracking which tasks
have become overdue.

## Use cases

| ID | Use Case | Actor | Trigger | Domains |
|---|---|---|---|---|
| UC-01 | Create Task | User | User submits a new task | tasks |
| UC-02 | Mark Task Overdue | System | Task's due date passes with no completion | tasks |
| UC-03 | Complete Task | User | User marks a task done | tasks |
