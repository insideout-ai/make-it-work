# Product

Mini Delivery Tracker lets a team create invoices for billed work and
track sprint velocity.

## Use cases

| ID | Use Case | Actor | Trigger | Domains |
|---|---|---|---|---|
| UC-01 | Create Invoice | User | User submits a billable line item | billing |
| UC-02 | Track Velocity | System | A sprint closes | velocity |

For detailed use case flows, see `/uc-01-create-invoice`, `/uc-02-track-velocity`.
