# Support

## Before opening an issue

Please check the [README troubleshooting guide](README.md#troubleshooting), update the marketplace and plugin, and reload Claude Code. This resolves most installation and stale-version problems.

## Ask a question or report a bug

Use [GitHub Issues](https://github.com/insideout-ai/make-it-work/issues) for usage questions, documentation problems, and reproducible bugs.

Include the following when it is relevant:

- Your Claude Code version (`claude --version`).
- The plugin version shown in `/plugin`.
- The installation channel: `claude-community` or `insideout-ai`.
- The skill you invoked and the command or prompt you used.
- The expected and actual behavior.
- A minimal reproduction or sanitized logs.

Remove credentials, private source code, customer data, and other sensitive information before posting.

## Feature requests

Open a [GitHub issue](https://github.com/insideout-ai/make-it-work/issues) describing the workflow problem, who experiences it, and the outcome you want. A concrete use case is more useful than a proposed implementation.

## Security reports

Do not disclose a suspected vulnerability in a public issue. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).
